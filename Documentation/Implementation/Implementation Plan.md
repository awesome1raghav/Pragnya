# Implementation Plan

The approved plan, divided into ten steps (26 November 2026). The reasoning, phase mapping, ownership tables
and risks are in [Architecture Reconciliation and Revised Plan](Architecture%20Reconciliation%20and%20Revised%20Plan.md).
Each step is started only on request and is complete only when its checks have actually run.

| Step | Scope | Done when | Status |
|---|---|---|---|
| 1 | **Frontend foundation and real data**: pinned deps, `/` → `/dashboard`, `/about`, new `/sources` `/lineage` `/intelligence`, real API layer, case context, system status, job monitor, backend search, honest "not available yet" pages; backend case objectives/category/last activity | Every route loads, deep links and back/forward work, honest states, create → upload → hash → metadata → integrity in the UI, checked with Playwright | **Done** (9/9 Playwright, 91 backend tests) |
| 2 | **Architecture documents and module contracts**: flowcharts stored verbatim, contract types, typed dependency registry, migration `0004` | `0004` upgrades and downgrades on an empty database; registry tests match the flowchart edge for edge with no cycles | **Done** (134 backend tests, 9/9 Playwright) |
| 3 | **T-MIR orchestration core**: Job Service, worker, planner, leases, retry, cancel, timeout, outbox, WebSocket, NEX-MET moved into T-MIR; Job / Analysis / T-MIR APIs; notifications | 202 job, worker runs it, live events, crash recovery without duplicates, image-only runs skip AUD/VID | **Done** |
| 4 | **Media intelligence** (NEX-MET complete, IMG, VID, AUD, PRV) with a documented detector comparison | Real results or explicit UNAVAILABLE for each engine | **Done** (detectors benchmarked; face-video detector pending a licensed test set) |
| 5 | **Origin and circulation** (NEX-SRC, FPM, MOC) + Neo4j and Qdrant projections; `/sources`, `/lineage` | SSRF tests, fingerprint precision/recall on a controlled set, projection rebuild | **Done** (Neo4j 5.26 projection with checkpoint, lag and rebuild, tested against the container; Qdrant deferred: no embedding model adopted) |
| 6 | **Correlation** (NEX-ALN, TRN, CMC) on a controlled ground-truth set | Offsets/trims/splices recovered within stated tolerance | **Done** (ground-truth tests; one execution per case covers all pairs) |
| 7 | **Investigation intelligence** (NEX-EGC, REC, INV, RPT); graph, timeline, review, reports pages | Traceable graph, separate reviews, versioned reports | **Done** (graph snapshots with a supporting record per edge; append-only versioned reviews; JSON + PDF reports with SHA-256; Playwright end to end) |
| 8 | **Remaining integration**: search of sources/findings/reports, notifications, settings, connection recovery | Multi-tab reconnect and reconciliation | **Done** (search across all six resource types; server-side preferences with optimistic concurrency, applied to notifications and automatic analysis; `/system/config`; reconnect resumes with `?after=`, retries on online/visible, refetches all if the event history restarted; two-tab and dropped-connection Playwright tests) |
| 9 | **Validation and hardening**: security, reliability, performance, backup, Dockerfiles, CI | Suites green on a clean runner | **Done** (backend suite in the clean Docker image: 254 passed, 9 skipped for absent PyTorch/weights/Neo4j; Origin guard, headers, CSP, rate limit, production guard; dependency audits clean; encrypted backup with verified restore drill; outage drill; measured performance; Dockerfiles, Compose `app`/`ci` profiles and CI workflow. The CI workflow itself has not run: nothing has been pushed) |
| 10 | **UI/UX refinement**: Playwright and screenshot audit | Findings fixed and re-verified | **Done** (automated audit of 32 routes at 1440 and 390 px: 4 hard and 9 soft findings plus 5 found by eye, all fixed; audit now reports 0) |
